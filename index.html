✿ What is Paku? ✿
パク — ちいさなターミナルのおともだち ♡

PAKU

Your tiny terminal companion.

A lightweight terminal companion for Windows developers, built to simplify system inspection, workspace management, cleanup, session context and everyday terminal tasks.

⬇ DOWNLOAD PAKU View Project →
♡ Windows Python 3.11+ ✿ v0.1.0

✿ What can Paku do? ✿
DoctorSystem and environment diagnostics.
System InfoView important machine information.
WorkspaceAnalyze projects and Git repositories.
CleanFind and clean temporary workspace files.
Save / ResumeKeep workspace context between sessions.
AutorunsInspect Windows startup entries.
DebloatManage selected Windows applications.
ThemesCustomize the terminal appearance.
